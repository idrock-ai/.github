# Security Policy

If you discover a security vulnerability in any IDROCK repository, model, or
service (including idrock.uz and eval.idrock.uz), please report it privately —
do **not** open a public issue.

- Email: [idrock@newuu.uz](mailto:idrock@newuu.uz) with the subject line
  `SECURITY: <short description>`
- Include: the affected repository or service, steps to reproduce, and the
  potential impact.

We will acknowledge your report within 5 business days. Please give us
reasonable time to fix the issue before any public disclosure.
